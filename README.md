AWS S3 Static Website Hosting

Project Overview

Deployed a static website using Amazon S3 to practise AWS cloud storage, website hosting, and bucket configuration.

AWS Services Used

* Amazon S3
* Static website hosting
* Bucket permissions and bucket policy

Implementation Steps

1. Created an S3 bucket.
2. Uploaded the website files.
3. Enabled static website hosting.
4. Configured access permissions.
5. Tested the website using its S3 website endpoint.

How to host a static website on Amazon S3 and configure the settings required to serve website content.
